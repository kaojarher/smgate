原《仙途遠征》的修仙故事，已改寫為「魔法門」（Might and Magic）風格的劍與魔法冒險。

## 故事
鐵拳城堡的「魔法之門」核心魔力水晶碎裂，守護恩洛斯大陸的結界只剩約 150 天。
你是羅蘭國王親授的見習騎士，要依序走過 **甜水鎮 → 銀灣 → 自由港 → 黑郡**，
找回替代的魔力水晶，最後深入 **深淵王座**，擊倒深淵魔王。
魔法之門能量充滿時，全隊可施展「魔門共鳴」召喚守護巨像，擊碎首領的魔法護盾。

## 檔案
```
index.html            頁面骨架與載入順序
css/style.css         樣式
js/safe-storage.js    localStorage 備援
js/sprite-map.js      圖資描述：精靈圖路徑與尺寸 + 圖塊座標（改圖只動這裡與 assets/）
js/core.js            遊戲主體（地圖、3D、戰鬥、存檔、精靈圖檢查）
js/features.js        擴充：守護巨像、精準瞄準、七大屬性、煉金、城堡…
js/items.js           傳送卷軸（已正式載入，並接上方向鍵旁 🧧 按鈕）
js/fx-lib.js          Canvas 特效庫（純 2D，不依賴遊戲）
js/fx-bridge.js       把特效接到攻擊／瞄準／怪物反擊
js/main.js            啟動
assets/img/           zen / zen2 / zen3 .png（精靈圖，尺寸固定，勿縮放）
assets/img/sheets-inline.js   僅 file:// 雙擊開啟時使用的 data-URI 備援
tools/check_sprites.py        圖塊座標檢查腳本

```

## 執行
- 建議：在此資料夾執行 `python3 -m http.server`，開 http://localhost:8000/
- 也可直接雙擊 index.html（file://），會自動改用 sheets-inline.js。
- three.js / rot.js 仍從 CDN 載入，需連網。

## 精靈圖「跑位」問題：原因與修正
**原因**：原壓縮檔根目錄 `assets/img/` 的三張圖不是原圖——副檔名是 .png，實際是 JPEG（沒有透明），
且 zen2 變成 1199×896、zen3 變成 1905×544；但 `sprite-map.js` 的 95 筆座標是依 1400×1046／900×257 量的，
所以裁出來會切到別人、露出底色。正確的圖在 `xiantu/assets/img/`（與內嵌 data-URI 一致），已換回。

**另外修正**：`w:🏛` 寬度 172→165（原本多包到帳篷的繩尾）、`m:🐀` 寬度 105→94（右側留白 12px 造成偏心）。

**之後如何避免再發生**：
1. 執行時檢查（`core.js` 的 `checkSheet`）：圖檔實際尺寸須等於 `SHEETS` 內的 `w/h`，否則拒用該圖、改顯示 emoji，
   並在日誌與主控台提示；同時逐一檢查每個圖塊是否超出圖檔、是否空白、邊緣是否被切到。結果在 `window.SPRITE_REPORT`。
2. 發佈前檢查：`python3 tools/check_sprites.py .`（需要 pillow、numpy），有問題會列出並以非 0 結束。
   少量「CUT 5～8px」是兩個圖塊緊貼（木箱／斧頭、神殿／帳篷），不是裁壞。
3. 改圖時請同步更新 `sprite-map.js` 的 `SHEETS` 尺寸與座標。
